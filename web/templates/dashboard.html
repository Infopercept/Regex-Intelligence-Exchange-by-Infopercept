API Example

Test the API with a simple curl command:

# Search for Apache patterns
curl -X GET "http://localhost:5000/api/patterns?q=apache&limit=5"

# Match patterns against text
curl -X POST "http://localhost:5000/api/match" \
  -H "Content-Type: application/json" \
  -d '{"text": "Server: Apache/2.4.41 (Ubuntu)"}'

# Get analytics summary
curl -X GET "http://localhost:5000/api/analytics/summary"
