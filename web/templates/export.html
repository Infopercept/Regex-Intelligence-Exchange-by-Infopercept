Export Information
Available Formats:
  • JSON: Complete pattern data including all regex patterns, metadata, and version information. Best for programmatic use and data integration.
  • CSV: Simplified tabular format with basic pattern information (vendor, product, category). Best for spreadsheet analysis and reporting.
Filtering:
  • Select a category to export only patterns from that category
  • When you select a category, the vendor dropdown will automatically show only vendors with patterns in that category
  • Select a vendor to further filter patterns to a specific vendor
  • Leave both filters empty to export all patterns
Usage Examples:
  • Export all web server patterns: Category = "web", Vendor = "All Vendors"
  • Export all Apache patterns: Category = "All Categories", Vendor = "Apache"
  • Export Apache web patterns: Category = "web", Vendor = "Apache"
  • Export everything: Category = "All Categories", Vendor = "All Vendors"
