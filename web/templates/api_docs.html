API Documentation

RESTful API for accessing technology fingerprinting patterns

Overview

The Regex Intelligence Exchange API provides programmatic access to our comprehensive pattern database with 1500+ technology fingerprinting patterns.

Base URL: http://127.0.0.1:5000/api

Description

Get all patterns with optional filtering and pagination.

Query Parameters
Parameter Type Description Example
q string Search query (vendor, product, keyword) apache
category string Filter by category web
vendor string Filter by vendor Apache
limit integer Number of results (max 100) 20
offset integer Pagination offset 0
Example Request
GET /api/patterns?q=apache&category=web&limit=5
Example Response
{
  "patterns": [
    {
      "vendor": "Apache",
      "vendor_id": "apache",
      "product": "Apache HTTP Server",
      "product_id": "apache",
      "category": "web",
      "subcategory": "web-server",
      "all_versions": [...]
    }
  ],
  "total": 17,
  "offset": 0,
  "limit": 5
}

Description

Get detailed information about a specific pattern.

Path Parameters
Parameter Type Description
vendor_id string Vendor identifier
product_id string Product identifier
Example Request
GET /api/patterns/apache/apache

Description

Match patterns against input text to identify technologies.

Request Body
{
  "text": "Server: Apache/2.4.41 (Ubuntu)"
}
Example Response
[
  {
    "vendor": "Apache",
    "product": "Apache HTTP Server",
    "vendor_id": "apache",
    "product_id": "apache",
    "pattern_name": "Apache Server Header",
    "matched_text": "Server: Apache/2.4.41",
    "version": "2.4.41",
    "category": "web"
  }
]
