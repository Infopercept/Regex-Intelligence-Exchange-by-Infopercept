Pattern Testing Guide
How to Use the Pattern Tester

The Pattern Tester analyzes text to identify technologies using over 1500 regex patterns.

Best Input Types
  • HTTP Response Headers - Server, X-Powered-By, etc.
  • HTML Source Code - Meta tags, comments, scripts
  • Server Responses - Error messages, banners
  • Application Output - Version strings, footers
Interpreting Results
  • Product - The identified technology
  • Vendor - The company or organization
  • Version - Detected version (when available)
  • Matched Text - The exact text that triggered the match
Advanced Features
  • Export Results - Download findings as JSON or CSV
  • Filter by Category - Focus on specific technology types
  • Pattern Details - View exact regex patterns used
